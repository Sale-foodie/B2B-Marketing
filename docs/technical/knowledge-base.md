# 知识库设计

## 概述

LeadKits 使用 Dify 内置的知识库功能，为 AI Agent 提供领域知识支撑。知识库内容以文档形式上传到 Dify，通过向量检索 (RAG) 在 Agent 对话/推理时提供上下文。

## 知识库清单

| 编号 | 知识库名称 | 服务的 Agent | 用途 |
|------|-----------|-------------|------|
| KB-1 | 行业分类知识库 | ICP Builder, Supervisor | 标准行业分类体系和关键词 |
| KB-2 | 产品使用帮助 | ICP Builder | 引导用户使用产品的 FAQ |
| KB-3 | B2B 销售方法论 | AI Analysis | 销售策略和最佳实践 |
| KB-4 | ICP 最佳实践 | ICP Builder | ICP 构建的指导框架 |
| KB-5 | 行业采购结构链 | ICP Builder, Scoring | 各行业的采购决策链 |
| KB-6 | 行业与产业关联 | Supervisor, Scoring | 行业间的上下游关系 |
| KB-7 | 话术模版 | AI Analysis | 各场景的沟通话术参考 |

## 各知识库详细设计

### KB-1：行业分类知识库

**用途**：帮助 ICP Builder Agent 理解和映射行业分类，帮助 Supervisor 生成准确的搜索关键词。

**内容结构**：
- 国标行业分类（GB/T 4754）主要类别
- 每个行业的常见子行业
- 行业别名和关联关键词
- 行业代码与天眼查行业参数的映射

**示例条目**：
```
行业：信息传输、软件和信息技术服务业
  - 子行业：软件开发、互联网平台、数据处理
  - 关联关键词：SaaS、云计算、大数据、人工智能、IT服务
  - 天眼查行业代码：I65
  - 典型企业规模：20-500人
```

### KB-2：产品使用帮助

**用途**：当用户在 ICP 构建对话中遇到困惑时，Agent 可以引用帮助内容进行解答。

**内容结构**：
- ICP 是什么，为什么重要
- 如何描述你的目标客户
- 各字段的填写指南
- 常见问题 FAQ

### KB-3：B2B 销售方法论

**用途**：为 AI Analysis Agent 提供销售策略知识，生成更专业的触达建议。

**内容结构**：
- SPIN 销售法
- 挑战者销售模式
- MEDDIC 销售方法论
- 不同行业的销售周期特点
- 不同职位决策人的沟通要点

### KB-4：ICP 最佳实践

**用途**：帮助 ICP Builder Agent 引导用户构建高质量的 ICP。

**内容结构**：
- ICP 构建框架（公司维度 + 联系人维度）
- 常见 ICP 模板示例
- ICP 验证清单（如何判断 ICP 是否有效）
- 常见错误（ICP 过宽/过窄）

**示例模板**：
```
ICP 模板：企业服务 SaaS 公司
  公司维度：
    - 行业：企业服务、SaaS
    - 规模：50-500 人
    - 融资：A轮-C轮
    - 地区：一线城市
    - 信号：正在数字化转型
  联系人维度：
    - 职位：CTO/VP Engineering/技术总监
    - 决策角色：最终决策者或关键影响者
    - 关注点：技术效率、团队生产力
```

### KB-5：行业采购结构链

**用途**：帮助理解不同行业的采购决策链条，辅助 ICP 评分和分析。

**内容结构**：
- 各行业典型采购决策人
- 采购决策流程
- 采购周期和预算范围
- 采购触发事件

**示例条目**：
```
行业：制造业
  采购决策链：
    - 需求提出：生产部门/IT部门
    - 技术评估：IT总监/CTO
    - 商务谈判：采购部
    - 最终审批：VP或CEO（取决于金额）
  采购周期：3-6个月
  典型预算：10万-100万/年
  触发事件：产线升级、数字化转型、降本增效
```

### KB-6：行业与产业关联

**用途**：帮助 Supervisor 扩展搜索范围，帮助评分识别关联行业。

**内容结构**：
- 上下游产业链关系
- 相关行业映射
- 跨行业客户画像共性

### KB-7：话术模版

**用途**：为 AI Analysis Agent 生成触达建议时提供参考话术。

**内容结构**：
- 冷启动邮件模版
- 首次电话话术
- LinkedIn 连接请求模版
- 跟进邮件模版
- 不同行业的定制话术

## 知识库管理

### 更新策略

| 知识库 | 更新频率 | 更新方式 |
|--------|----------|----------|
| 行业分类 | 每年 | 手动更新 |
| 产品帮助 | 按需 | 产品迭代时更新 |
| 销售方法论 | 每季度 | 内容团队维护 |
| ICP 最佳实践 | 按需 | 积累案例后更新 |
| 采购结构链 | 每半年 | 行业调研后更新 |
| 产业关联 | 每年 | 手动更新 |
| 话术模版 | 每月 | 根据效果反馈迭代 |

### Dify 知识库配置

| 配置项 | 推荐值 |
|--------|--------|
| 分段方式 | 按段落自动分段 |
| 最大分段长度 | 1000 tokens |
| 检索模式 | 混合检索（向量 + 关键词） |
| 返回 Top K | 3-5 |
| 相似度阈值 | 0.7 |
