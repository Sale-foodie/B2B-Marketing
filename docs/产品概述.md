# 产品概述

## 产品愿景

打造国内中小 B2B 团队首选的智能获客平台，让每个销售人员都能用最低的成本、最短的时间精准找到并触达目标客户。

## 核心问题

当前国内 B2B 获客面临四大痛点：

### 1. 工具碎片化

企业搜索用天眼查、联系人找领英、邮件用 Mailchimp、CRM 又是另一个系统。工具之间数据割裂，SDR 每天在多个工具之间反复切换，效率极低。

### 2. 人力成本高

SDR 团队花大量时间在手动搜索、整理数据、写邮件上，真正用于销售沟通的时间不足 30%。中小团队往往没有专职 SDR，创始人需要自己兼顾获客。

### 3. 线索质量差

缺乏系统化的线索评分机制，销售团队把大量精力花在低质量线索上。没有 ICP 驱动的筛选逻辑，搜索结果杂乱，转化率低。

### 4. 缺少智能化

传统工具只做数据查询，不具备智能分析能力。无法自动识别高价值客户、生成触达建议、预测购买意向。

## 解决方案

LeadKits 以 **ICP（理想客户画像）为核心驱动**，将获客全流程整合到一个平台：

```
定义 ICP → 搜索企业 → 发现 Lead → ICP 评分 → AI 分析 → 跟进管理
```

通过 Dify（AI Agent 编排）+ n8n（数据工作流）的组合架构，实现从线索发现到商机管理的端到端自动化。

### 核心差异化

| 维度 | 传统工具 | LeadKits |
|------|----------|----------|
| 驱动方式 | 用户手动搜索 | ICP 智能驱动搜索 |
| 数据处理 | 手动整理、对比 | AI 自动富化、评分、分析 |
| 工具数量 | 需要 3-5 个工具 | 一个平台搞定 |
| 适用门槛 | 需要专业 SDR | 创始人一人也能用 |

## 产品定位

- **阶段**：个人项目，MVP 阶段
- **目标市场**：国内中小 B2B 团队（5-50 人公司）
- **切入场景**：创始人/销售负责人需要快速找到目标客户
- **定价策略**：低门槛，让中小团队负担得起
